# Ecuavóley: Pasión Ecuatoriana

Sitio educativo desarrollado únicamente con HTML5 para la práctica de Programación de Plataformas Web.

## Archivos
- `index.html`: presentación e imagen con hipervínculo.
- `historia.html`: historia y tradición.
- `reglas.html`: lista ordenada, lista desordenada y lista de definiciones.
- `posiciones.html`: tabla con `thead`, `tbody`, `tr`, `th`, `td`.
- `galeria.html`: imágenes y audio local.
- `images/`: cinco ilustraciones originales SVG.
- `audio/`: simulación sonora original de silbato en WAV.

## Antes de entregar
1. Reemplaza `[ESCRIBE TU NOMBRE COMPLETO]` en el footer de las cinco páginas.
2. Reemplaza `estudiante@ejemplo.com` por tu correo real, tanto en el texto como en `mailto:`.
3. Comprueba que las cinco páginas, las imágenes y el audio funcionen.
4. Sube los archivos al repositorio GitHub y habilita GitHub Pages desde la rama principal, carpeta raíz `/`.
5. Entrega los dos enlaces y una captura de la página principal abierta desde GitHub Pages.

No se usan CSS, JavaScript, bibliotecas, plantillas ni estilos inline. El atributo `border="1"` de la tabla es HTML tradicional para hacer visibles los bordes, no CSS.

Las imágenes son ilustraciones SVG, no fotografías. Si tu profesor exige fotografías reales, reemplaza los archivos por fotografías con permiso de uso y actualiza las rutas y textos alternativos.
